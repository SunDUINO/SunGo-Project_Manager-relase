# [EN] SunGo Snippet Manager – Setup & Usage Guide

SunGo includes a built-in library of ready-made Go code snippets, organized by category, plus the ability to save your own.  
Access it via the **✂️ Snippet Manager** entry in the SunGo Tools panel.

---

## 🔍 Finding a snippet

Type into the search box to filter by title, description, or tag across every category at once. Click a snippet's card to expand it and see the full code before deciding to use it.

---

## 🖱️ Using a snippet

Each expanded snippet gives you two options:

| Button | What it does |
|--------|--------------|
| **Insert** | Pastes the snippet directly at your cursor position in the active editor |
| **Copy** | Copies the code to your clipboard, for pasting wherever you like |

---

## ➕ Adding your own snippets

Click **"+ Add Snippet"** to open the editor: give it a title, a short description, some comma-separated tags (used for search), and the code itself. Your own snippets appear alongside the built-in ones and can be deleted at any time — built-in snippets can't be deleted, only your own custom ones.

---

## ⚠️ Common Issues

**Can't find a snippet I know exists** – Try a shorter or more general search term; the search matches title, description, and tags, but not the code body itself.

**Inserted snippet has the wrong indentation** – The snippet is inserted as-is at the cursor position; if your cursor was already indented, you may end up with double indentation on subsequent lines — a quick "Format Document" (`Shift+Alt+F`) usually cleans this up.

**My custom snippet disappeared** – Custom snippets are stored per-installation, not per-project. If you switched VS Code profiles or reinstalled the extension, custom snippets created under a different profile won't carry over automatically.

# [PL] SunGo Snippet Manager – Instrukcja instalacji i użytkowania

SunGo zawiera wbudowaną bibliotekę gotowych snippetów kodu Go, uporządkowaną w kategorie, oraz możliwość zapisywania własnych.  
Dostęp przez wpis **✂️ Snippet Manager** w panelu SunGo Tools.

---

## 🔍 Szukanie snippetu

Wpisz w pole wyszukiwania, żeby filtrować po tytule, opisie lub tagu we wszystkich kategoriach naraz. Kliknij kartę snippetu, żeby ją rozwinąć i zobaczyć pełny kod przed podjęciem decyzji o użyciu.

---

## 🖱️ Użycie snippetu

Każdy rozwinięty snippet daje dwie opcje:

| Przycisk | Co robi |
|----------|---------|
| **Insert** | Wkleja snippet bezpośrednio w pozycji kursora w aktywnym edytorze |
| **Copy** | Kopiuje kod do schowka, do wklejenia gdziekolwiek chcesz |

---

## ➕ Dodawanie własnych snippetów

Kliknij **"+ Add Snippet"**, żeby otworzyć edytor: podaj tytuł, krótki opis, kilka tagów oddzielonych przecinkami (używanych do wyszukiwania) oraz sam kod. Twoje snippety pojawiają się obok wbudowanych i można je usunąć w dowolnym momencie — wbudowanych snippetów nie da się usunąć, tylko własne, niestandardowe.

---

## ⚠️ Częste problemy

**Nie mogę znaleźć snippetu, który na pewno tam jest** – Spróbuj krótszej lub bardziej ogólnej frazy; wyszukiwanie dopasowuje tytuł, opis i tagi, ale nie samą treść kodu.

**Wstawiony snippet ma złe wcięcie** – Snippet jest wstawiany dokładnie tak jak jest, w pozycji kursora; jeśli kursor był już wcięty, kolejne linie mogą mieć podwójne wcięcie — szybkie "Format Document" (`Shift+Alt+F`) zwykle to porządkuje.

**Mój własny snippet zniknął** – Własne snippety są zapisywane per instalacja, nie per projekt. Jeśli zmieniłeś profil VS Code albo przeinstalowałeś rozszerzenie, własne snippety z innego profilu nie przeniosą się automatycznie.
